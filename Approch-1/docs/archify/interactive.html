Workflow & Sequence — claim through the system

Sequence (one claim)
  1. Form (13 fields) → validation
  2. preprocessor.transform (29)
  3. Model pick: _pick_model(requested) → ranked fallback if busy
  4. predict + predict_proba → verdict
  5. Header X-Routed-From / X-Served-By if rerouted
  6. Log → prediction_log.txt + latency
Agent chain (approach 3)
  1. Intake → fact sheet (45 fields)
  2. Policy / Anomaly / History (rule evidence)
  3. Risk → calibrated p
  4. Coordinator → base band → may escalate to REVIEW
  5. Reasoning → narrative (Gemini or local)
  6. Persist → /api/report/{id}
